## 🚀 How to Use

### **Option 1: Copy from Text Files**
1. Open the `.txt` files in this folder
2. Copy the code blocks
3. Paste into your existing `.ipynb` notebooks
4. Replace the OpenAI code with Llama versions

### **Option 2: Create New Notebooks**
1. Create new `.ipynb` files in VS Code
2. Copy the content from the `.txt` files
3. Save with descriptive names

### **Option 3: Use Existing Llama Files**
Some notebooks already have Llama versions (like "1. Messages - Llama.ipynb")

## 🔧 Setup Requirements

- ✅ **Virtual environment activated** (`source venv/bin/activate`)
- ✅ **Llama running** (`ollama run llama3.2:3b`)
- ✅ **AutoGen packages installed** (already done)
- ✅ **Jupyter kernel configured** (use "AutoGen (venv)")

## 🚨 Troubleshooting

### **Import Errors**
- Ensure virtual environment is activated
- Check that AutoGen packages are installed

### **Llama Connection Issues**
- Verify Ollama is running: `ollama list`
- Check model is available: `ollama run llama3.2:3b`

### **Jupyter Issues**
- Select correct kernel: "AutoGen (venv)"
- Restart VS Code after configuration changes
